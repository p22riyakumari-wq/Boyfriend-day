BOYFRIEND DAY WEBSITE

1. Open index.html in a browser to preview the website.
2. To add photos, create an "images" folder beside index.html.
3. Replace a photo placeholder, for example:
   <div class="photo"><img src="images/photo1.jpg" alt="Our memory"></div>
4. Add this CSS if you use real images:
   .photo img { width:100%; height:100%; object-fit:cover; border-radius:20px; }

You can edit the names, memories, reasons and letter directly in index.html.
